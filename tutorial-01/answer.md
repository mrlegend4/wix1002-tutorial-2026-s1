| Input | Process | Output |

### Question 6: Print the minimum number from 10 random numbers generated by computer.

#### 1. Input-Process-Output (IPO) Model

| Input | Process | Output |
|---|---|---|
| 10 generated integers (0–100) | Compare the numbers to find the minimum | The 10 numbers and the minimum number |

#### 2. Pseudocode

```text
START
    minimum ← RANDOM_INTEGER(0, 100)
    DISPLAY minimum
    count ← 1
    WHILE count < 10 DO
        n ← RANDOM_INTEGER(0, 100)
        DISPLAY n
        IF n < minimum THEN
            minimum ← n
        END IF
        count ← count + 1
    END WHILE
    DISPLAY minimum
STOP
```

#### 3. Flowchart

```mermaid
flowchart TD
    A([Start]) --> B["minimum ← RANDOM_INTEGER(0, 100)"]
    B --> C[/Display minimum/]
    C --> D["count ← 1"]
    D --> E{"count < 10?"}
    E -- Yes --> F["n ← RANDOM_INTEGER(0, 100)"]
    F --> G[/Display n/]
    G --> H{"n < minimum?"}
    H -- Yes --> I["minimum ← n"]
    H -- No --> J["count ← count + 1"]
    I --> J
    J --> E
    E -- No --> K[/Display minimum/]
    K --> L([Stop])
```

### Question 7: Count the number of odd and even numbers from 10 random numbers generated by the computer.

#### 1. Input-Process-Output (IPO) Model

| Input | Process | Output |
|---|---|---|
| 10 generated integers (10–100) | Check whether each number is even or odd and count them | The 10 numbers, odd count, and even count |

#### 2. Pseudocode

```text
START
    even = 0
    odd = 0
    count = 0
    WHILE count < 10 DO
        n = RANDOM_INTEGER(10, 100)
        DISPLAY n
        IF n % 2 = 0 THEN
            even = even + 1
        ELSE
            odd = odd + 1
        END IF
        count = count + 1
    END WHILE
    DISPLAY even, odd
STOP
```

#### 3. Flowchart

```mermaid
flowchart TD
    A([Start]) --> B["even = 0, odd = 0, count = 0"]
    B --> C{"count < 10?"}
    C -- Yes --> D["n = RANDOM_INTEGER(10, 100)"]
    D --> E[/Display n/]
    E --> F{"n % 2 = 0?"}
    F -- Yes --> G["even = even + 1"]
    F -- No --> H["odd = odd + 1"]
    G --> I["count = count + 1"]
    H --> I
    I --> C
    C -- No --> J[/Display even, odd/]
    J --> K([Stop])
```

### Question 8: Count the number of alphabet U and M from a sentence entered by user.

#### 1. Input-Process-Output (IPO) Model

| Input | Process | Output |
|---|---|---|
| One complete sentence | Inspect each character and count the occurrences of `U` and `M` | Separate `U` count and `M` count |

#### 2. Pseudocode

```text
START
READ sentence
uCount ← 0
mCount ← 0
i ← 0
WHILE i < LENGTH(sentence) DO
    ch ← CHARACTER_AT(sentence, i)
    IF ch = 'U' THEN
        uCount ← uCount + 1
    ELSE IF ch = 'M' THEN
        mCount ← mCount + 1
    END IF
    i ← i + 1
END WHILE
DISPLAY uCount, mCount
STOP
```

#### 3. Flowchart

```mermaid
flowchart TD
    A([Start]) --> B[/Read sentence/]
    B --> C["uCount = 0, mCount = 0, i = 0"]
    C --> D{"i < sentence length?"}
    D -- Yes --> E["Read character at i: ch"]
    E --> F{"ch = 'U'?"}
    F -- Yes --> G["uCount = uCount + 1"]
    F -- No --> H{"ch = 'M'?"}
    H -- Yes --> I["mCount = mCount + 1"]
    H -- No --> J["i = i + 1"]
    G --> J
    I --> J
    J --> D
    D -- No --> K[/Display uCount, mCount/]
    K --> L([Stop])
```

### Question 9: Display the frequency of a keyword from a web page

#### 1. Input-Process-Output (IPO) Model

| Input | Process | Output |
|---|---|---|
| Extracted page text and one keyword | Normalize case; split into words; count exact matches | Keyword and frequency |

#### 2. Pseudocode

```text
START
READ pageText, keyword
VALIDATE keyword is one non-empty word
words ← TOKENIZE(LOWERCASE(pageText))
count ← 0
FOR EACH word IN words DO
    IF word = LOWERCASE(keyword) THEN
        count ← count + 1
    END IF
END FOR
DISPLAY keyword, count
STOP
```

#### 3. Flowchart

```mermaid
flowchart TD
    A([Start]) --> B[/Read pageText, keyword/]
    B --> C{"Is keyword one non-empty word?"}
    C -- No --> D[/Display invalid keyword message/]
    C -- Yes --> E["words = TOKENIZE(LOWERCASE(pageText))"]
    E --> F["count = 0, i = 0"]
    F --> G{"i < number of words?"}
    G -- Yes --> H{"words[i] = LOWERCASE(keyword)?"}
    H -- Yes --> I["count = count + 1"]
    H -- No --> J["i = i + 1"]
    I --> J
    J --> G
    G -- No --> K[/Display keyword, count/]
    D --> L([Stop])
    K --> L
```

### Question 12: Guess a random number generated by computer.

#### 1. Input-Process-Output (IPO) Model

| Input | Process | Output |
|---|---|---|
| A fixed random target and repeated guesses | Compare guess with target; repeat while unequal | Higher, Lower, or Correct; attempt count |

#### 2. Pseudocode

```text
START
target ← RANDOM_INTEGER(1, 100)
attempts ← 0
REPEAT
    READ guess
    IF guess < 1 OR guess > 100 THEN
        DISPLAY "Enter 1–100"
    ELSE
        attempts ← attempts + 1
        IF guess < target THEN
            DISPLAY "Higher"
        ELSE IF guess > target THEN
            DISPLAY "Lower"
        ELSE
            DISPLAY "Correct", attempts
        END IF
    END IF
UNTIL guess = target
STOP
```

#### 3. Flowchart

```mermaid
flowchart TD
    A([Start]) --> B["Generate target from 1 to 100"]
    B --> C["attempts = 0"]
    C --> D[/Read guess/]
    D --> E{"Guess within 1-100?"}
    E -- No --> F[/Display Enter 1-100/]
    F --> D
    E -- Yes --> G["attempts = attempts + 1"]
    G --> H{"guess < target?"}
    H -- Yes --> I[/Display Higher/]
    I --> D
    H -- No --> J{"guess > target?"}
    J -- Yes --> K[/Display Lower/]
    K --> D
    J -- No --> L[/Display Correct, attempts/]
    L --> M([Stop])
```
