# Tutorial 1

## Part I

### Question 1: Request two numbers from the user and print the multiplication of the numbers.

#### 1. Input-Process-Output (IPO) Model

| Input | Process | Output |
|---|---|---|
| `num1`, `num2` | Multiply `num1` by `num2` | Product |

#### 2. Pseudocode

```text
START
    READ num1
    READ num2
    product ← num1 × num2
    DISPLAY product
STOP
```

#### 3. Flowchart

```mermaid
flowchart TD
    A([Start]) --> B[/Read num1/]
    B --> C[/Read num2/]
    C --> D[product ← num1 × num2]
    D --> E[/Display product/]
    E --> F([Stop])
```

### Question 2: Determine whether a random number is greater than 50.

#### 1. Input-Process-Output (IPO) Model

| Input | Process | Output |
|---|---|---|
| Random integer `n` (0–100) | Check whether `n > 50` | Number and comparison result |

#### 2. Pseudocode

```text
START
    n ← RANDOM_INTEGER(0, 100)
    IF n > 50 THEN
        DISPLAY n, "Greater than 50"
    ELSE
        DISPLAY n, "Not greater than 50"
    END IF
STOP
```

#### 3. Flowchart

```mermaid
flowchart TD
    A([Start]) --> B["n ← RANDOM_INTEGER(0, 100)"]
    B --> C{"n > 50?"}
    C -- Yes --> D[/Display n, Greater than 50/]
    C -- No --> E[/Display n, Not greater than 50/]
    D --> F([Stop])
    E --> F
```

| Input | Process | Output |
|---|---|---|

### Question 4: Print the results of the two players’ dice game.

|---|---|---|

### Question 6: Print the minimum number from 10 random numbers generated by computer.

#### 1. Input-Process-Output (IPO) Model

| Input | Process | Output |
|---|---|---|
| 10 generated integers (0–100) | Compare the numbers to find the minimum | The 10 numbers and the minimum number |

#### 2. Pseudocode

```text
START
    minimum ← RANDOM_INTEGER(0, 100)
    DISPLAY minimum
    count ← 1
    WHILE count < 10 DO
        n ← RANDOM_INTEGER(0, 100)
        DISPLAY n
        IF n < minimum THEN
            minimum ← n
        END IF
        count ← count + 1
    END WHILE
    DISPLAY minimum
STOP
```

#### 3. Flowchart

```mermaid
flowchart TD
    A([Start]) --> B["minimum ← RANDOM_INTEGER(0, 100)"]
    B --> C[/Display minimum/]
    C --> D["count ← 1"]
    D --> E{"count < 10?"}
    E -- Yes --> F["n ← RANDOM_INTEGER(0, 100)"]
    F --> G[/Display n/]
    G --> H{"n < minimum?"}
    H -- Yes --> I["minimum ← n"]
    H -- No --> J["count ← count + 1"]
    I --> J
    J --> E
    E -- No --> K[/Display minimum/]
    K --> L([Stop])
```

### Question 7: Count the number of odd and even numbers from 10 random numbers generated by the computer.

#### 1. Input-Process-Output (IPO) Model

| Input | Process | Output |
|---|---|---|
| 10 generated integers (10–100) | Check whether each number is even or odd and count them | The 10 numbers, odd count, and even count |

#### 2. Pseudocode

```text
START
    even = 0
    odd = 0
    count = 0
    WHILE count < 10 DO
        n = RANDOM_INTEGER(10, 100)
        DISPLAY n
        IF n % 2 = 0 THEN
            even = even + 1
        ELSE
            odd = odd + 1
        END IF
        count = count + 1
    END WHILE
    DISPLAY even, odd
STOP
```

#### 3. Flowchart

```mermaid
flowchart TD
    A([Start]) --> B["even = 0, odd = 0, count = 0"]
    B --> C{"count < 10?"}
    C -- Yes --> D["n = RANDOM_INTEGER(10, 100)"]
    D --> E[/Display n/]
    E --> F{"n % 2 = 0?"}
    F -- Yes --> G["even = even + 1"]
    F -- No --> H["odd = odd + 1"]
    G --> I["count = count + 1"]
    H --> I
    I --> C
    C -- No --> J[/Display even, odd/]
    J --> K([Stop])
```

## Part II

### Question 8: Count the number of alphabet U and M from a sentence entered by user.

#### 1. Input-Process-Output (IPO) Model

| Input | Process | Output |
|---|---|---|
| One complete sentence | Inspect each character and count the occurrences of `U` and `M` | Separate `U` count and `M` count |

#### 2. Pseudocode

```text
START
READ sentence
uCount ← 0
mCount ← 0
i ← 0
WHILE i < LENGTH(sentence) DO
    ch ← CHARACTER_AT(sentence, i)
    IF ch = 'U' THEN
        uCount ← uCount + 1
    ELSE IF ch = 'M' THEN
        mCount ← mCount + 1
    END IF
    i ← i + 1
END WHILE
DISPLAY uCount, mCount
STOP
```

#### 3. Flowchart

```mermaid
flowchart TD
    A([Start]) --> B[/Read sentence/]
    B --> C["uCount = 0, mCount = 0, i = 0"]
    C --> D{"i < sentence length?"}
    D -- Yes --> E["Read character at i: ch"]
    E --> F{"ch = 'U'?"}
    F -- Yes --> G["uCount = uCount + 1"]
    F -- No --> H{"ch = 'M'?"}
    H -- Yes --> I["mCount = mCount + 1"]
    H -- No --> J["i = i + 1"]
    G --> J
    I --> J
    J --> D
    D -- No --> K[/Display uCount, mCount/]
    K --> L([Stop])
```
